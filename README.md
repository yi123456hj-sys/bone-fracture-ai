# BoneScan AI — Bone Fracture Intelligence Dataset

> Interactive medical X-ray dataset website · EN / 中文 / 한국어

**Live demo:** https://&lt;your-username&gt;.github.io/bone-fracture-ai

---

## Features

- **10 Fracture Types** — Avulsion, Comminuted, Dislocation, Greenstick, Hairline, Impacted, Longitudinal, Oblique, Pathological, Spiral
- **Interactive Annotation** — Draw circles on X-rays to mark fracture locations (mouse & touch)
- **Medical Detail Panel** — Causes, Treatment, Recovery for every fracture type
- **3 Languages** — English · 中文 · 한국어
- **Data Visualization** — Chart.js charts for distribution and version comparison
- **Fully Responsive** — Works on mobile, tablet, and desktop

## Deploy to GitHub Pages

1. Create a new repository on GitHub: `bone-fracture-ai`
2. Push this project:
   ```bash
   git remote add origin https://github.com/<your-username>/bone-fracture-ai.git
   git branch -M main
   git push -u origin main
   ```
3. Go to **Settings → Pages → Source: Deploy from branch → main → / (root)**
4. Your site will be live at `https://<your-username>.github.io/bone-fracture-ai`
